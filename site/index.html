Équations & hypothèses du modèle

Pr = Pe − αL − NcLc − NsLs − pertes de couplage − autres pertes. Marge = Pr − sensibilité.

Δτch = |Dch| Δλ L ; Δτtotal = √(Δτch² + Δτmodal²) ; BPmodèle = 700 / Δτtotal (ps), en GHz. BP = min(BPmodèle, BPcatalogue).

Catalogue pédagogique : PIN −52 dBm, PIIPN −64 dBm ; B·L = 10 MHz·km (saut d’indice) et 100 MHz·km (gradient). Constantes modales : n₁ = 1,468 et Δ = 0,01.

La longueur maximale reprend l’estimation Python : pertes fixes à leur valeur configurée, dispersion chromatique et limite catalogue. La dispersion modale n’est pas incluse dans cette estimation ; vérifiez la bande passante à la longueur choisie. Les positions des connexions sont réparties uniformément pour la courbe à cassures.
